# AgenDoc

AgenDoc es una plataforma Web y Mobile para la gestión de consultorios médicos, diseñada para facilitar la administración de pacientes, agendas médicas y citas.

## Tecnologías

### Backend

- Java 21
- Spring Boot
- PostgreSQL
- Flyway

### Frontend Web

- React
- TypeScript
- Vite

### Mobile

- React Native
- Expo
