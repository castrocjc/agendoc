# Docker

## Estado

Durante el desarrollo del MVP de AgenDoc no se utilizarán contenedores Docker.

El entorno local utilizará:

- PostgreSQL instalado localmente.
- Spring Boot ejecutado desde el IDE o Maven.
- React + Vite para la aplicación Web.
- React Native + Expo para la aplicación Mobile.

## Futuro

La carpeta `docker` queda reservada para futuras configuraciones relacionadas con:

- Docker Compose.
- Contenedorización del Backend.
- Bases de datos para entornos compartidos.
- Despliegues mediante contenedores.

La incorporación de Docker será evaluada cuando el proyecto evolucione hacia ambientes de integración, pruebas o producción.
